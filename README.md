# Visual Language Library

SAVL — South American Visual Language and EGPT — Egyptian Visual Language, published as an Obsidian-style reference library.

Open the website: https://wizardboxhub.github.io/visual-language-library/

The site includes reference notes, image boards, search, and a link graph. Images retain their source credits in the notes; image rights belong to their respective creators and institutions. No blanket image reuse licence is granted by this repository.

## Updating

Edit the original Obsidian vault, export with Webpage HTML Export, and replace `docs/savl/` or `docs/egpt/` with the updated website. Keep the landing pages and `.nojekyll` file. Commit and push to `main`; GitHub Pages publishes the `docs` folder.

This repository contains the exported website only. Obsidian settings, credentials, and private application files are excluded. EGPT is published under `docs/egpt/`, including its 100-symbol hieroglyph library.

The export runtime is provided by Webpage HTML Export; its MIT licence is in EXPORTER-LICENSE.txt.
